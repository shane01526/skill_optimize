# Info Digest（變體 B：嚴格對齊來源、標衝突與缺口）

- **只用提供的來源**：把每一份來源當唯一事實依據，逐條核對，不引入任何來源外的知識。
- **標註衝突**：來源互相矛盾時，兩邊都寫出來並標明分歧，不要自行裁決。
- **標註缺口**：需求問到但來源沒有的資訊，明確寫「來源未提及」。
- **附來源編號**：每個陳述後面標它來自哪一份來源。
- 遵守指定的長度與格式。
