# Info Digest（變體 A：先列要點再濃縮、逐源對齊）

綜整多份來源材料成一份摘要的有效流程：

1. **逐源抽取要點**：把每一份來源（S1、S2…）各自的關鍵事實列出來，標上來源編號，確保**一份都不漏**。
2. **對齊與去重**：合併重複資訊；若來源之間**有衝突**，明確標註「S1 與 S3 對 X 的說法不同」，不要擅自選邊或抹平。
3. **濃縮成稿**：依需求的**長度上限**與**格式**（如條列 / 段落）產出，每個重點盡量標注來源（S1）。
4. **忠實原則**：只寫來源裡有的事實；**不得外加**來源沒有的推測或背景知識。無法從來源判斷的，就說「來源未提及」。
5. **自我檢查**：交稿前確認 (a) 每個來源都被涵蓋、(b) 沒超過長度、(c) 沒有捏造。
