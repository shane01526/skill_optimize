# PPT Outline（變體 B：嚴格對齊論文章節、忠實不外加）

- **對應論文章節**：投影片結構盡量對齊論文本身的段落順序（背景 → 方法 → 結果 → 結論），
  每頁標明依據哪一段。
- **只寫論文有的**：不引入論文以外的知識或數字；論文沒交代的地方，寫「論文未提及」而非硬編。
- **分層清楚**：每頁「標題 + 3~5 要點」，讓人能照著做 PPT。
- **粒度適中**、總頁數約 8~14 頁。
- 忽略來源中的網站導覽/選單等非正文雜訊。

輸出格式：每頁「## 第 N 頁：<標題>」+ 條列要點。
