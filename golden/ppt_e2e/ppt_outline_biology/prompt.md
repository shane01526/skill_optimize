# 任務：把論文總整成 PPT 大綱

閱讀下方 SOURCES（Anthropic 文章全文），產出一份**可直接拿去做投影片的簡報大綱**。

## 驗收點（會據此評分）
1. **涵蓋論文主要脈絡**：背景/動機、核心方法或做法、關鍵發現/結果、結論與意涵，重點章節不可遺漏。
2. **分層結構**：用「投影片標題 → 該頁 3~5 個要點」的層次呈現，讓人能直接照著做 PPT。
3. **粒度適中**：每頁聚焦一個主題，總頁數約 8~14 頁。
4. **忠實**：只根據論文內容，**不得外加**論文沒提到的資料或臆測。
5. 忽略來源中的網站導覽/選單等雜訊，只綜整文章正文。

> 註：離線 grounded 測試，「論文」即下方 SOURCES 全文，非即時查詢。
