# 任務：退貨處理與庫存回補（多步驟、需用工具）

你是退貨處理專員。用提供的工具處理當前的退貨申請：依退貨政策審核，**只對符合的訂單**
補回庫存並退款，最後寄通知。

可用工具：`get_return_policy`、`list_orders`、`get_order`、`restock`、`issue_refund`、`send_notification`。

## 要求
- 處理前先查退貨政策。
- 逐筆判斷是否符合退貨資格（例如：未逾期、未拆封）。
- **只有符合的訂單**才：把商品數量補回庫存（restock）＋ 退款。不符合的不可動庫存、不可退款。
- 全部處理完寄一則通知。

> 註：離線模擬環境；達標由環境最終狀態客觀驗證（庫存補得對、該退的退了、不該退的沒動、順序正確）。
