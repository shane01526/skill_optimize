# 任務：退款核准（深難、多步驟、需用工具、政策衝突＋預算上限＋連動扣點）

你是退款核准專員。用提供的工具處理今天這批退款申請。**重要：本系統的寫入工具不會替你把關**
——`issue_refund` 你叫它退多少它就退多少、`deduct_loyalty` 你扣多少就扣多少，是否合規完全由你負責。

可用工具：`get_refund_policy`、`list_requests`、`get_request`、`issue_refund`、`deduct_loyalty`、`send_notification`。

## 要求
- **處理前先查政策**（`get_refund_policy`），內含優先序、每日預算、連動扣點規則。
- **依優先序逐筆判定資格**（高到低）：
  1. 詐欺標記（fraud）→ 一律不退。
  2. 促銷代碼 FINAL → 一律不退（即使 VIP 也蓋過）。
  3. VIP 客戶退款窗較長（vip_days）；一般客戶為 base_days；逾期不退。
- **處理順序**：符合者 VIP 優先，其餘按申請 id 升冪。
- **每日預算上限**：逐筆累計已退金額，**任何會使累計超過每日預算的申請一律 defer（今天不退）**。
- **連動扣點**：每一筆成功退款，都要對該客戶扣除 `floor(退款金額 / 10)` 點會員點數。
- 全部處理完寄一則通知。

> 註：離線模擬環境；達標由環境最終狀態客觀驗證（該退的退了且金額對、不該退的沒退、超預算的 defer、
> 連動扣點正確、且寫入前有先查政策）。環境不會擋你，錯誤會真的落地。
