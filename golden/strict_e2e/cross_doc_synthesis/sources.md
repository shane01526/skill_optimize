# SOURCES（4 份文獻，關於新藥 Zynolate 臨床試驗）

## D1（原廠新聞稿）
Zynolate 第三期試驗顯示對目標疾病的反應率達 68%，共納入 1,200 名受試者，安全性良好、副作用輕微。

## D2（獨立學術期刊）
針對同一試驗的再分析指出，反應率經校正後約為 54%（原廠數字未調整基線差異）；
樣本數與原廠一致（1,200 人）。作者提醒長期安全性資料仍不足。

## D3（監理機關摘要）
監理審查文件記載受試者為 950 人（非 1,200），並列出 3 起嚴重不良事件，
結論為「療效證據中等，需追蹤長期安全性」。

## D4（產業分析報告）
分析師認為若獲批，Zynolate 年銷售上看 20 億美元；此報告未討論療效或安全性細節，僅談市場面。
