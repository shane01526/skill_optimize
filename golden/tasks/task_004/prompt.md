# Task 004：多輪對話（非 coding，達標靠使用者行為訊號）

這是一個**多輪對話**範例任務：使用者請 agent 幫忙寫一段文字，然後在下一輪給出回饋。
**達標與否不靠 LLM 評分**，而是由規則式 completion detector 從「使用者接下來的回覆」推斷
（正向確認/採用 → 達標；負向/重述/要求重來 → 未達標）。

`conversation.json` 依變體給不同的後續回饋，示範同一任務下「好 skill 讓使用者滿意、
弱 skill 讓使用者要求重來」如何被行為訊號捕捉。真實情境中這些後續回覆來自 Codex log 的
下一個 user turn（Phase 2）。
